# VELVET PASSPORT NOW — PRODUCTION GATE 0 (66 PARCOURS)

**Règle de fabrication : aucun parcours ne passe au montage si son paquet de ressources n'est pas inventorié avant la production.** Paris 05 demeure l'exception pilote, à régulariser. Le but est de ne plus rechercher une photographie au milieu du montage.

## A. Paquet MASTER obligatoire en amont (FR et EN)

Pour chaque parcours, réunir avant génération :
- Les 11 segments ou le nombre de segments effectivement approuvé, récits, transitions et cues.
- La correspondance **Stop / phrase / objet historique / image exacte**. Aucun « photo à trouver » silencieux.
- Chaque photographie : ID stable, nom du fichier, source primaire, page de l'institution, date/photographe, légende factuelle, preuve de licence, attribution, empreinte SHA-256.
- Les façades actuelles : photographies authentiques propres ou sous licence adéquate ; distinguer clairement les vues historiques.
- Les portraits : identité documentée, identité contestée = HOLD.
- Les manques : enregistrer dès le Gate 0 une solution éditoriale explicite sans création de fausse scène.
- Les scripts FR/EN et le traitement de voix préapprouvé ; droits commerciaux des voix vérifiés.

## B. États des fichiers (univoques)

FOUND → VERIFIED → RIGHTS-CLEARED → PRODUCTION-READY.
Un élément sans preuve suffisante reste HOLD et ne reçoit jamais RIGHTS-CLEARED par simple ancienneté ou nom de licence copié d'un tableau.

## C. Un seul pipeline, 66 parcours

1. **Gate 0** : réunir et vérifier les scripts, images et licences ; comparer les images aux phrases.
2. **Gate 1** : figer les deux textes, les identités, les lieux et les composants visuels ; répertorier les manques et solutions.
3. **Gate 2** : générer les voix FR/EN en parallèle, mesurer les durées et aligner les cues par reconnaissance vocale. Aucune estimation par nombre de caractères.
4. **Gate 3** : rendre les films complets FR/EN et sous-titres à partir de la même timeline, avec placeholders uniquement en mode contrôle privé.
5. **Gate 4** : QA humain ciblé sur les échecs audio, anachronismes, erreurs d'identification et droits ; corrections incrémentales.
6. **Gate 5** : publier seulement lorsque licences, droits de voix, QA et approbation explicite sont tous positifs.

## D. Règles d'accélération

- Toujours produire les deux langues sur le même cycle ; aucune reprise de pipeline par ville.
- Vérification des droits **une fois par asset** dans un registre commun, réutilisé par tous les parcours ; crédit unique et cache de preuve.
- Ne jamais faire de nouvelles recherches pour une image déjà rejetée sans nouvelle preuve.
- Jamais de visuel IA présenté comme archive ; jamais d'archive contextuelle légendée comme photographie précise des faits.
- Aucun lancement public automatique ni achat de licences sans consentement.
